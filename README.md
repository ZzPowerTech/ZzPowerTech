## 🧩 Projetos em destaque

### 🕹️ **AusTV Network**
Rede de servidores de Minecraft 1.20.1, com foco em:
- ⚔️ PvP balanceado (1.8 e 1.9)
- 💎 Itens e encantamentos customizados
- 🌍 Mundo e eventos personalizados
- 💰 Economia integrada e sistema de lootbox

> Responsável pela **gestão financeira**, **agenda de eventos** e **planejamento de expansão**.

---

### 🌱 **Horta Autônoma Hidropônica**
Sistema inteligente de monitoramento e controle de cultivo hidropônico usando sensores e IoT:
- Monitoramento de **pH**, **temperatura** e **condutividade**
- Controle automático da **bomba de água** e **luminosidade**
- Integração com **Raspberry Pi** para controle remoto via dashboard

---

### 🧫 **Monitoramento de Bioprodutos**
Sistema sensorial para acompanhar colônias bacterianas em biorreatores:
- Sensor de **turbidez da água**
- Identificação de **agentes contaminantes**
- Monitoramento em tempo real com dashboard web

---

### 💰 **Financeiro AusTV**
Sistema web de gestão financeira da rede AusTV:
- **Frontend:** Angular / Next.js  
- **Backend:** NestJS + PostgreSQL (via Prisma)  
- **Integração:** Mercado Pago  
- **Funcionalidades:** Dashboard, controle de receitas/despesas, relatórios e permissões de acesso
